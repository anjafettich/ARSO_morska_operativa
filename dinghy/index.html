Hidra api

Api za servis podatkov od Hidra3.0 za online aplikacijo Lojze/Marko. Docker teče na dinghyu.

Hidra vizualizacija.

Poženeš docker hidra:

docker-compose up -d --build

Za debugging brez detached:

docker-compose up -- build
docker-compose down

docker inspect hidra
docker logs traefik | grep hidra

Interaktivno gres v docker in lahko spreminjaš datoteke znotraj tega dockerja

docker exec -it hidra bash

Pregled rezultatov na serverju gea:

https://gea.arso.gov.si/vg2020-dev/hidra/showHIDRAjson?date=2021041500
https://gea.arso.gov.si/vg2020-dev/hidra/listHIDRAjson

Get json:

wget  --output-document=test.json  https://gea.arso.gov.si/vg2020-dev/hidra/showHIDRAjson?date=2021041500

  • Hidra*.json, ki se kopirajo na /scratch/jjerman/metSrvData/Hydra/

Git:

http://gitportal.arso.sigov.si/afettich/hidra

Vhodni podatki

Vhodni podatki so napovedi Hidra3 (.json), ki jih na /scratch kopira skripta:

/home/momo_si/oper/ecflow/hidra3/scripts/prod/archive/archive_hidra3.ecf

cp -f  ${WORKDIR}/Hidra3_${RUNDATE}_${hourR}.json  /scratch/jjerman/metSrvData/gribs/Hydra/Hidra_${RUNDATE}00.json

Kopira se tudi rezultate za nazaj,ker je na /scratch naštimano brisanje starejših datotek kot 2 dni:

cp -f /home/momo_si/results_oper/hidra3/hidra3_results/hidra3Files/Hidra_${YEAR}${month}*.json /scratch/jjerman/metSrvData/gribs/Hydra/ || true
cp -f /home/momo_si/results_oper/hidra3/hidra3_results/hidra3Files/Hidra_${YEAR}${lastmonth}*.json /scratch/jjerman/metSrvData/gribs/Hydra/ || true

Ti rezultati so potem vidni izven ARSO preko Hidra apija.
