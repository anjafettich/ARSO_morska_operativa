Arhiviranje operative

1x mesečno potrebno prestaviti morsko operativo iz /mnt/archive/ na /archive_dmf/ (trakovi) in potem pobrisati /mnt/archive/.

Tekoči arhiv:

/mnt/archive/momo_si/$model/$YYYY/

Arhiv na trakovih:

/archive_dmf/momo_si/$model/$YYYY/

kopiranje na dmf

priporocljivo preko ventusdmf
ssh momo_si@ventusdmf

pogledas katere datoteke se bo kopiralo

rsync -avn momo_si@10.149.1.3:/data_nfs/archive/momo_si/$model/$YYYY/* /data_nfs/archive_dmf/oper/model/$model/$YYYY/

rsync datotek

time rsync -auv momo_si@10.149.1.3:/data_nfs/archive/momo_si/$model/$YYYY/* /data_nfs/archive_dmf/oper/model/$model/$YYYY/

HF radar

Naredis zip: 

/home/momo_si/anja/archiving/zipHFradar.sh (v skripti definiraj ${YYYY})

Rsync na archive_dmf:

time rsync -auv momo_si@10.149.1.3:/data_nfs/archive/momo_si/hf_radar/${YYYY}/* /data_nfs/archive_dmf/oper/observ/hfradar/product/currents/${YYYY}/

nemo_storm_surge

Za nemo ssh_KP: naredis zip: 

/home/momo_si/anja/archiving/zipNemoSurge.sh  (v skripti definiraj ${YYYY})

Premaknes file v pravilno strukturo ${YYYY}/MM/DD/:

mv *.gz ./${YYYY}/

Premaknes file v mesečno strukturo:

for i in {01..12}; do mkdir $i;mv nemo_storm_surge_${YYYY}$i*.gz ./$i/; done

Skripta premakne file v dnevno strukturo:

/home/momo_si/anja/archiving/archiveNemoStormSurge.sh   (v skripti definiraj ${YYYY})

Potrebno je samo narediti rsync cca 1x mesecno:

time rsync -auv momo_si@10.149.1.3:/data_nfs/archive/momo_si/nemo_storm_surge/ssh_kp/${YYYY}/* /data_nfs/archive_dmf/oper/model/nemo_storm_surge/nemo_storm_surge_fc/${YYYY}/
