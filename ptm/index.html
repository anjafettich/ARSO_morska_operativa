ecflow suita

nemo4

Priprava nemo datotek, potrebnih za sledenje delcev, kadar želimo pognati sledenje delcev za nazaj.

Vhodne parametre in nastavitve nastaviš v:

/home/momo/nemo4/ecflow/include/options.h

export startdate=20240624
export RUNDATE=20240624
export enddaterun=20240624
export iRun='hourly'

Če potrebuješ nemo datoteke za sledenje delcev (vzame iz /archive_dmf)

export iPTM=true

Če želiš nemoNADR, je potrebno najprej pognati nemo in pripraviti robne in začetne pogoje za nemoNADR. 

export iNADR=true

nemo4NADR

Priprava nemoNADR datotek, potrebnih za sledenje delcev, kadar želimo pognati sledenje delcev za nazaj.

Vhodne parametre in nastavitve nastaviš v:

/home/momo/nemo4NADR/ecflow/include/options.h

export startdate=20240624
export RUNDATE=20240624
export enddaterun=20240624

ptm_run

Zagon sledenja delcev za nazaj.

Najprej si moraš pripraviti vhodne podatke (nemo, nemoNADR ali wera).
Za tekoči mesec so podatki v: 

/mnt/ceph/oper/momo_si/results/

Primer za nemo:

Podatki za sledenje delcev (isto kot je potem v /archive_dmf)

/mnt/ceph/oper/momo_si/results/nemo/nemo_fc/2025/01/01/NEMO_ptm_20250101.tar.gz

Celotni nemo zagoni za tekoči mesec:

/mnt/ceph/oper/momo_si/results/nemo/nemo_results/

Tekoči podatki za ptm:

/mnt/ceph/oper/momo_si/results/particle_tracking/

Vhod v ptm:

NADR_surface_20250110.nc
NEMO_surface_20250110.nc
wera_surface_20250110.nc

Za dejanski vhod v PTM se naredi merge vseh datotek tipa NEMO_surface_DATUM.nc v NEMO_surface_input_PTM.nc in OpenDrift bere samo to datoteko.

Podatke tipa $model_surface_$RUNDATE.nc skopiraš v:

/mnt/ceph/users/momo/PTM_input/

Vhodne parametre in nastavitve nastaviš v:

/home/momo/ptm_run/ecflow/include/options.h

Start date for simulation

export startdate=20241126

Starting hour for simulation

export starthour=11

Duration of simulation in hours

export numHours=3

Location

export lon=13.65
export lat=45.63
export domain='wera' # 'adr' ,'nadr' # 'wera' (only for Backtracking)

Object:

export objInd=99

For backtracking simulation set to True

export iBack=True

Only for oil: (objInd=99 )

Duration of oil release (in hours):

export duration=0

Type of oil: 

export oilType=2

Oil mass: 

export oilMass=1000
