ecFlow

Uporablja se ecFlow verzija 5 server na formanu,

ecFlow_ui poganjamo pod svojim uporabniškim imenom (zaenkrat ni nobene zaščite)

Za zagon operativnih ecflow serverjev skrbi root, preverja na 5 minut, zamik 60 sek, da je po reboot čas, da so dostopni moduli, Operativni ecflow serverji:

a_si
camx 
nowcast 
momo_si 
mospro 
momo

Felicia root cron:

*/5 * * * * sleep 60; /root/bin/check_ecflow_server.sh 1>> /var/log/check_ecflow_server.log 2>&1 &
*/5 * * * * /root/bin/check_ecflow_server_5_5_3.sh 1>> /var/log/check_ecflow_server_5_5_3.log 2>&1 &

Vsak uporabnik sam zažene svoj ecflow server:

module load python2/2.7.11 ecFlow/5.3.1-f
ecflow_start.sh 
host=$(hostname)
server port number($ECF_PORT number) - default 1500 + $UID

ecflow server

V noči iz četrtka na petek spravi in počisti ecf.log datoteko.

Felicia momo_si cron

58 23 * * 4 /home/momo_si/ecflow_server/saveandclear_ecflog.sh 11593 1> /dev/null 2>&1 &

ecflow log server da lahko spremljamo output datoteke tudi ko poženemo ecflow_ui na lokalnem računalniku

Potrebne tudi default končnice (kot v ecmwf) task.jobTRYNO.jid (namesto task.q), task.jobTRYNO, task.TRYNO (namesto task.jobTRYNO.eo)

ecflow_ui

Naloži potrebne module:

module load python2/2.7.11   
module load ecFlow/5.3.1-f

Zaženi ecFlow_ui pod svojim uporabniškim imenom (zaenkrat ni nobene zaščite). vključi si prikaz serverja.

"momo_si"   ecfport=11593 host=felicia 
"momo"      ecfport=11576 host=felicia
"myrs"      ecfport=3142  host=ecflow-oper1.arso.sigov.si

Nadzorni sistem ICINGA

Na vsako minuto izvede skripto, ki preveri status določene suite.

  • ob spremembah (nove suite, ...) potrebno preveriti, prilagoditi - izpisuje log datoteko, ki mora imeti zaščito (-rw-rw-rw-)
  • tudi direktorij drwxrwxrwx /home/momo_si/oper/controlnagios/
